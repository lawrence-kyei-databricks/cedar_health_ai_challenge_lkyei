## 4. Agent Inference Table (distinct from app)

The coding agent's calls are traced in the SAME gateway inference table but attributed
to the user principal (lawrence.kyei@databricks.com), while app calls are attributed to
the service principal (8d72bbdf-c646-4e56-9316-4fe4a4b32718).

Query to distinguish:
  SELECT requester, COUNT(*) as calls, status_code
  FROM ai_challenge_esc.cedar_health_gateway.cedar_health_assistant_payload
  WHERE requester = 'lawrence.kyei@databricks.com'  -- agent/user calls
  GROUP BY requester, status_code
